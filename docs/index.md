# JavaGems3D Engine

JavaGems3D is a game engine written in Java.

Current version: **beta 1.0**  
Development started in: **Autumn 2022**

Repository: https://github.com/gltexture/javagems3d

---

## 📌 Overview

This engine is primarily designed for small-scale and experimental game projects.

It is still under active development, and many features are either incomplete or not yet implemented. The architecture and APIs may change significantly over time.

---

## ⚠️ Status

- The engine is still in active development
- Stability is not fully guaranteed in all scenarios
- Some systems are experimental or partially implemented
- Performance and memory optimizations are ongoing
- The engine is already usable for development and experimentation, but should be treated as evolving software
